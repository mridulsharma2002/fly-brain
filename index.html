Brain surgery

How it works

The brain is real

The wiring comes from FlyWire, the first complete map of an adult fruit fly brain: 139,255 neurons and their connections, traced from electron microscope images. The firing rules come from the whole-brain model by Shiu et al. (Nature, 2024). Each neuron adds up its inputs, leaks a little, and fires when it crosses a threshold.

Running all 139k neurons would melt a phone, so I ran the full brain on a server first. I fed it sugar, bitter and touch, kept every neuron that ever fired, and kept the real connections between them. That's the 867 you see, and it still behaves like the full brain for these senses.

The body is mine

The brain has no legs here, so a few lines of code connect its outputs to a toy body. I picked the outputs by testing which neurons fire for sugar, bitter and touch on each side:

sugarSide = decoder(106 output neurons)  // fitted on 440 brain runs
turn  = sugarSide
      + (sugar fading ? turn harder : 0)
      - bitter(L) + bitter(R)   // DNp42, DNge067
      - touch(L)  + touch(R)    // DNg35, DNg84
eat   = MN9 > threshold          // proboscis motor neuron
back  = bitter or touch too high

Left versus right sugar isn't one neuron. It's spread across about 100 output neurons, so a small linear decoder reads it, the same trick neuroscientists use on real recordings.

Every input to that code is a neuron's firing rate. Nothing in it knows where the sugar is.

Honest notes

  • Real flies find food from far away by smell. In this model, the smell circuit runs away and lights up 10,000 neurons at once, so sugar reaches the brain through its taste neurons instead.
  • Wall bumps go in through touch neurons on the antennae. Lemons go in through bitter taste neurons.
  • The brain doesn't learn here. It's the same wiring every time, so what you see is instinct.
